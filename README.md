# VeloxDesk (ВелоксДеск)

Полнофункциональная enterprise-система техподдержки (helpdesk / service desk): приём и обработка обращений клиентов через омниканальные шлюзы (Web, Email, Telegram), живой чат с оператором в реальном времени, база знаний, SLA-контроль, гибкая аналитика и конструктор отчётов, автоматизация («Диспетчер»), ролевой доступ и корпоративная аутентификация (LDAP/SSO).

Состоит из двух приложений с поддержкой **Progressive Web App (PWA)**:
- **Клиентский портал** (`/`) — публичное приложение для клиентов: регистрация, подача и отслеживание тикетов, чат с поддержкой, база знаний, оценка качества (CSAT), привязка Telegram-аккаунта. Устанавливается как автономное PWA-приложение на телефон или ПК.
- **Операторское приложение** (`/staff/`) — рабочее место специалистов поддержки и администраторов: очередь тикетов, реалтайм-чат, макросы, внутренние заметки, дашборды, отчёты и полное управление системой. Устанавливается как PWA-приложение.

## О проекте

VeloxDesk — современная платформа службы поддержки для обслуживания клиентов через удобные им каналы: через веб-портал, электронную почту или Telegram-бота. Обращения из всех источников попадают в единый центр обработки, где операторы ведут переписку в реальном времени.

Система спроектирована под высокие нагрузки и команды от нескольких специалистов до десятков операторов с тысячами одновременно активных клиентов. Успешно прошла нагрузочное тестирование на профиле ~1500 активных клиентов + 30 операторов в реальном времени.

## Технологический стек

| **Поиск** | Elasticsearch 8 (с русской и английской морфологией) — полнотекстовый поиск по тикетам и статьям |
| **Хранилище файлов** | S3-совместимое объектное хранилище (MinIO) с валидацией MIME-типов по содержимому (magic bytes) |
| **Frontend** | React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons, TipTap Editor, QR Code |
| **PWA** | VitePWA (Service Worker, Web Manifest, Workbox, Background Sync, кеширование статики) |
| **Управление состоянием** | Zustand (persist) + TanStack React Query (инвалидация, кеширование, оптимистичные апдейты) |
| **Каналы связи** | Telegram Bot Webhook (двусторонний), Nodemailer (SMTP), IMAP-поллинг (входящая почта), тестовый Greenmail |
| **Перевод и i18n** | i18next (RU, UK, EN), DeepL API (автоматический перевод названий справочников) |
| **Безопасность** | TOTP 2FA (RFC 6238), Cloudflare Turnstile CAPTCHA, LDAP / Active Directory, OIDC SSO (Entra ID, Okta), bcrypt |
| **Мониторинг** | Prometheus, Grafana, Blackbox Exporter (Healthchecks) |
| **Инфраструктура** | Docker Compose, nginx (reverse proxy, rate-limiting, SSL termination, HTTP/2, Let's Encrypt) |

## Архитектура монорепозитория

Проект организован в виде монорепозитория на базе NX:

```
apps/
├── user-service          — регистрация, аутентификация (локальная/LDAP/OIDC), 2FA, пользователи, роли, группы прав
├── ticket-service         — тикеты, вложения, SLA, автоматизация, кастомные поля, Telegram- и Email-инжестия, DeepL
├── chat-service            — Socket.IO gateway, реалтайм-чат, статус присутствия, исходящие сообщения в Telegram
├── knowledge-service    — база знаний, публичные FAQ, полнотекстовый поиск (Elasticsearch)
├── analytics-service     — отчёты, метрики, динамика, KPI, дашборды, аудит настроек и тикетов
├── notification-service — фоновая отправка уведомлений и email-рассылок (BullMQ)
└── api-gateway           — внутренний микросервисный шлюз

frontend/
├── client-portal   — PWA-портал для клиентов (доступен по корню `/`)
└── operator-app     — PWA-приложение для операторов и администраторов (доступно по пути `/staff/`)

libs/
├── common          — криптография, валидаторы, интеграция с DeepL, Turnstile, токены
├── database        — сущности TypeORM, база данных, миграции
└── types           — общие TypeScript-интерфейсы, DTO, перечисления (enums)
```

Все микросервисы изолированы за обратным прокси `nginx`, межсервисное взаимодействие построено на прямых защищённых вызовах и шине событий Redis (Pub/Sub для мгновенных live-оповещений и BullMQ для гарантированной доставки).

## Омниканальность

VeloxDesk объединяет обращения из разных источников в единые диалоговые цепочки:

1. **Web-портал**:
   - Клиенты подают обращения через удобную форму с валидацией, прикреплением файлов и динамическими полями.
   - Живой чат с оператором прямо в браузере.

2. **Telegram-канал**:
   - **Двусторонняя интеграция**: клиент пишет боту в Telegram — автоматически создаётся тикет. Ответы оператора мгновенно приходят клиенту в чат Telegram, а ответы клиента появляются в веб-панели оператора.
   - **Медиа и файлы**: поддержка отправки фото, документов и голосовых сообщений между Telegram и Helpdesk.
   - **Связывание аккаунтов**: клиент может привязать свой Telegram в личном кабинете через одноразовый защищённый токен.
   - **Оповещения администраторам**: бот моментально присылает администраторам уведомления о новых заявках на регистрацию клиентов.
   - **CSAT в Telegram**: после закрытия тикета бот отправляет клиенту интерактивный опрос удовлетворённости качеством поддержки.

3. **Email-канал**:
   - Письмо на почту поддержки автоматически превращается в тикет, а отправитель регистрируется как клиент.
   - Ответы из почтового клиента добавляются в существующую цепочку сообщений тикета без дублирования.

## Полный список возможностей

### Тикеты и динамические справочники
- **Динамический справочник статусов (`ticket_statuses`)**:
  - Администратор может создавать произвольные статусы тикетов, настраивать их цвет (HEX), порядок сортировки, мультиязычные названия (RU, UK, EN), флаг завершения (`isClosed`) и признак учёта в расчёте SLA (`tracksSla`).
- **Динамический справочник типов тикетов (`ticket_types`)**:
  - Управление типами обращений (инцидент, консультация, запрос на обслуживание и т.д.) с весовыми коэффициентами для взвешенного расчёта KPI операторов.
- **Вложения**: загрузка файлов до 35 МБ на файл с валидацией реального типа по magic bytes (защита от маскировки исполняемых файлов).
- **Кастомные поля 8 типов**:
  - Текст, многострочный текст (Textarea), число, дата, чекбокс.
  - Поле-файл (прикрепление документа к конкретному атрибуту).
  - Поле с проверкой по регулярному выражению (Regex: номер договора, карта, телефон).
  - Иерархические зависимые выпадающие списки («категория → подкатегория»).
- **Метки (теги)**: свободная маркировка обращений, быстрые фильтры и статистика по меткам.
- **Слияние тикетов**: объединение повторяющихся тикетов с переносом всей истории сообщений и вложений.
- **VIP-клиенты**: выделение приоритетных клиентов специальным бейджем `VIP` в интерфейсе.
- **Массовые действия**: групповой ответ клиентам, массовое назначение исполнителя, закрытие, объединение и удаление.
- **Корзина**: мягкое удаление и возможность восстановления ошибочно удалённых обращений.
- **Экспорт**: выгрузка полной истории переписки и метаданных тикета в текстовый файл.

### Общение в реальном времени (чат)
- **Живой чат**: мгновенная доставка сообщений через WebSockets без перезагрузки страниц.
- **Внутренние заметки**: комментарии операторов внутри тикета, скрытые от клиента (для служебных пометок и передачи смен).
- **Индикаторы присутствия**:
  - «Оператор печатает…» / «Клиент печатает…».
  - «Сейчас просматривают» — отображение того, кто в данный момент держит тикет открытым.
- **Упоминания сотрудников**: синтаксис `@имя` в чате с отправкой браузерного уведомления и всплывающего тоста упомянутому коллеге.
- **Заготовки ответов (макросы)**: быстрые шаблоны ответов с динамическими подстановками имени клиента, оператора, номера тикета.
- **Статусы операторов**: «Онлайн», «Обед», «Совещание», «Перерыв» с автопереводом в статус «Неактивен» при бездействии.

### База знаний (FAQ)
- Публичный раздел статей, доступный клиентам даже без авторизации.
- Полнотекстовый поиск по статьям через Elasticsearch.
- Разделение на популярные и новые статьи, счётчики просмотров.
- Интерактивная оценка полезности статьи («Да / Нет») с защитой от накрутки.
- Кастомизация оформления базы знаний: администратор может внедрять свои CSS и JS для брендинга публичной базы знаний.

### Оценка качества (CSAT)
- Автоматический запуск опроса после закрытия тикета:
  - В виде баннера прямо в карточке тикета на портале.
  - Через интерактивные кнопки в Telegram-боте.
- Настраиваемый администратором список вопросов и шкала оценок.
- Детальная аналитика: средний балл по компании, распределение по операторам, отделам и динамика оценок.

### Хаб отчётов и аналитика
Комплексный аналитический модуль:
- **Дашборд**: оперативная статистика, тикеты по статусам, среднее время первого ответа (FRT), время решения (MTTR), % выполнения SLA.
- **Конструктор отчётов**:
  - **12 измерений группировки**: по оператору, клиенту, компании, отделу, статусу, приоритету, типу, каналу обращения (Web / Email / Telegram), метке (тегу), SLA-политике, категории, периоду (день / неделя / месяц).
  - Взвешенный KPI с учётом сложности типов тикетов.
  - **Сохранённые отчёты**: возможность сохранять настроенные конфигурации фильтров и группировок для быстрого запуска.
  - Экспорт результатов в **CSV** и **XML**.
- **Отчёт в динамике**: временные графики объёма тикетов, динамика нагрузок и сезонности.
- **Отчёт по операторам**: хронометраж статусов присутствия, скорость возврата в диалог, % решений с первого ответа (First Contact Resolution).
- **Журнал аудита тикетов**: полная история каждого изменения в тикете.
- **Журнал аудита настроек**: детальный лог того, кто и когда менял системные параметры (SLA, права, кастомные поля, автоматизацию, настройки LDAP и OIDC).

### Автоматизация («Диспетчер»)
- Гибкий движок правил «Триггер → Условие → Действие»:
  - **Триггеры**: создание тикета, смена статуса, смена приоритета, ответ клиента, нарушение дедлайна SLA.
  - **Условия**: по теме, автору, каналу, приоритету, текущим значениям кастомных полей.
  - **Действия**: автоназначение отдела/исполнителя, автоматическая смена статуса/приоритета, установка кастомных полей.
- **Вычисляемые поля**: авторасчёт значений по математическим формулам на основе других атрибутов тикета.

### SLA и эскалации
- Политики SLA по времени первого ответа и полного решения в разрезе приоритетов (низкий, средний, высокий, срочный).
- Автоматическая эскалация обращений (повышение приоритета, уведомление руководства) при приближении или срыве срока.

### Безопасность и права доступа
- **Три базовые роли**: Клиент (`client`), Оператор (`operator`), Администратор (`admin`).
- **Группы прав (Permission Groups)**:
  - Ограничение видимости по отделам.
  - Режим «только свои тикеты».
  - Роль «Наблюдатель» (доступ к просмотру без возможности быть назначенным исполнителем).
  - **IP-белый список** (доступ только с разрешённых корпоративных IP/подсетей).
  - Обязательное требование 2FA для участников группы.
  - Ограниченный администратор (не может удалять или понижать других администраторов).
- **Двухфакторная аутентификация (TOTP)**: поддержка Google Authenticator, Microsoft Authenticator и совместимых приложений.
- **Корпоративная аутентификация**:
  - **LDAP / Active Directory** с автоматической синхронизацией пользователей.
  - **SSO / OIDC** (Microsoft Entra ID, Okta, Keycloak).
  - Раздельные профили провайдеров для сотрудников и клиентов.
- **Защита от ботов (Cloudflare Turnstile)**: невидимая и интерактивная защита форм регистрации и входа.
- **Подтверждение регистрации клиентов администратором**:
  - Новые клиенты после регистрации попадают в очередь модерации (колокольчик в шапке панели оператора).
  - Мгновенный пуш в браузер клиента при подтверждении заявки администратором (автоматический бесшовный вход).
- **Мгновенная инвалидация сессий**: принудительное завершение всех сессий пользователя в реальном времени при его блокировке администратором.

### Интерфейс, адаптивность и PWA
- **Progressive Web App (PWA)**: оба приложения оснащены Service Worker и Web Manifest, поддерживают автономный запуск на Android, iOS, Windows и macOS.
- **Адаптивность**: продуманный интерфейс, протестированный на мобильных экранах (от 390px — iPhone), планшетах и десктопах. Удобное мобильное меню-шторка, оптимизированные карточки тикетов и поля ввода.
- **Темы оформления**: Светлая, Тёмная и Теплая (Modern Warmth).
- **Мультиязычность**: Русский, Украинский, Английский.

## Инструкция для нового пользователя (клиента)

1. **Откройте портал** (`https://<ваш-домен>/`) и нажмите кнопку «Зарегистрироваться».
2. **Заполните форму**: введите имя, email, надёжный пароль и пройдите быструю проверку на робота (Cloudflare Turnstile).
3. **Ожидание модерации**: откроется экран ожидания подтверждения администратором.
4. **Автоматический вход**: как только администратор нажмёт «Активировать», экран **сам, без перезагрузки**, отобразит «Добро пожаловать в VeloxDesk» и выполнит вход в личный кабинет.
5. **Создание обращения**: нажмите «Новый тикет», укажите тему, описание и при необходимости прикрепите файлы или скриншоты (Ctrl+V).
6. **Чат**: переписывайтесь со специалистом службы поддержки в реальном времени прямо в тикете.
7. **Подключение Telegram**: в личном кабинете привяжите Telegram, чтобы получать уведомления и отвечать в чат прямо из мессенджера.
8. **Оценка качества**: после закрытия тикета оцените качество решения вопроса (через баннер на портале или в Telegram).

## Возможности оператора

Оператор видит очередь обращений своего отдела и работает с тикетами:
- Фильтрация по статусам, приоритетам, исполнителям, отделам, меткам, пресет «Неприсвоенные».
- Создание и сохранение собственных пресетов фильтров таблицы тикетов.
- Реалтайм-чат с форматированием текста, загрузкой скриншотов из буфера и вложений.
- Оставление внутренних заметок (жёлтый фон), невидимых клиенту.
- Быстрые макросы с автоподстановкой параметров тикета и клиента.
- Упоминание коллег через `@имя`.
- Объединение дубликатов обращений, маркировка тегами, экспорт истории диалога.
- Просмотр карточки клиента, истории предыдущих обращений и статуса VIP.
- Управление статьями базы знаний (создание, редактирование, публикация).
- Управление своим статусом («Онлайн», «Обед», «Перерыв»).

## Возможности администратора

Администратору доступны все функции оператора, а также полное конфигурирование платформы:

- **Управление пользователями**: ручное создание сотрудников, модерация заявок клиентов, принудительный сброс 2FA и паролей, блокировка учётных записей.
- **Группы прав**: настройка видимости отделов, IP-белых списков, обязательной двухфакторной аутентификации.
- **Динамические статусы и типы тикетов**: создание и редактирование статусов и типов, выбор цветов, локализованные названия (RU/UK/EN).
- **Справочники**: категории и подкатегории, справочники компаний и городов.

- **Корпоративный вход**: настройка интеграций с Active Directory (LDAP) и SSO (OIDC/SAML/OAuth).
- **Автоматизация**: создание правил «Диспетчера» и вычисляемых полей.
- **SLA**: настройка нормативных сроков реакции и решения, правил автоматической эскалации.
- **Кастомные поля**: проектирование дополнительных полей любых типов с условной видимостью и зависимостями.
- **Хаб отчётов**: конструктор отчётов по 12 срезам, сохранение шаблонов, аналитика CSAT, журнал аудита действий и системных настроек.
- **Кастомизация базы знаний**: подключение корпоративных стилей (CSS) и скриптов (JS) к публичному порталу.

   ```bash
   npx nx run-many -t serve --all --parallel=9
   ```
